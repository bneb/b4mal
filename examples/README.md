# `examples/`

A collection of operational reference implementations demonstrating `b4mal` in varied contexts.

- **`hello.pipeline.ts`**: A rudimentary demonstration of the `Command Line Interface` configuration.
- **`shadow_demo/`**: An empirical exhibition of the orchestrator identifying and rejecting deterministic data masking across an `Overlay Filesystem`.
- **`polyglot-war/`**: Illustrates `b4mal` executing across disparate runtimes (`TypeScript` and `Python`), maintaining rigorous formal isolation regardless of the underlying language.
